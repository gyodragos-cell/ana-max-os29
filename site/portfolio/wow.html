One expression made the difference

Qwen 7B patch — incomplete
scores = np.dot(
    query / query_norm,
    doc_vectors.T / doc_norm
)

Normalizing after transposition does not respect matrix dimensions.

GPT-6 correction — verified
scores = np.dot(
    query / query_norm,
    (doc_vectors / doc_norm).T
)

Normalize each document first, then transpose the matrix.
